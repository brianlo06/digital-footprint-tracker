# Provider contract tests

The local synthetic breach boundary covers success, empty, duplicate, malformed, hostile, timeout, authentication, rate-limit, outage, pagination, and schema-change behavior. Invocation tests require exact tenant ownership, active account and identity state, a self-verified email no more than 24 hours old, and purpose-specific Phase 2 consent. Ledger tests prove that missing limits mean zero, reservations are idempotent, dispatched failures consume request quota, releases restore undispatched capacity, and daily/monthly request and cost caps fail closed. No provider test uses a live credential, personal identifier value, captured response, or network call.
