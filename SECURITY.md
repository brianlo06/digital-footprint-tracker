# Security Policy

This repository is currently non-functional and accepts no real personal information. Please do not use public issues to disclose a vulnerability that could expose identifiers, credentials, or another person’s data. Use a private maintainer channel once one is published.

Future security reports should include impact, affected component, reproduction using synthetic data, and suggested mitigation. Do not test against real users, third-party sites, or provider accounts without written authorization.

The proposed security baseline is documented in [docs/SECURITY.md](docs/SECURITY.md) and [docs/THREAT_MODEL.md](docs/THREAT_MODEL.md).
